x402 · Solana Mainnet · Live

The signal endpoint.
Pay with USDC to access it.

A paywalled market intelligence endpoint. No API key, no account, no OAuth. An AI agent hits it, gets a 402, sends 0.1 USDC on-chain, retries with the transaction signature, and gets the signal back after the server verifies the transfer independently. The whole flow runs on Solana mainnet with real money.

How the flow works
01
Agent calls GET /api/signal with no header
Server returns 402 with payment wallet address and amount in headers.
02
Agent calls request_funding()
Tally sends a Telegram notification with a deep link showing the exact amount and task. HMAC-signed, ±5 min window.
03
User taps card + biometric on the Auth screen
Session wallet is funded. The vault key never leaves the device. The agent only sees the session wallet.
04
Agent reads the payment wallet from the 402 headers and sends 0.1 USDC on-chain
Real SPL token transfer on Solana mainnet. No intermediary.
05
Agent retries with X-Tally-Session and X-Tally-Tx headers
Server verifies the USDC transfer on-chain independently, then returns the signal.
06
Agent calls return_funds()
Remaining balance sweeps back to the master vault automatically. USDC ATA closed, rent reclaimed.
Agent code (Python)
from warm_vault_auth import request_with_payment

result = request_with_payment(
    url="https://tally.lll.mk/api/signal",
    amount_usdc=0.1,
    task_description="Fetch SOL/USDC market signal",
    return_funds_after=True,  # sweeps remainder back to vault
)

if result["ok"]:
    signal = result["data"]["signal"]
    print(f"Signal: {signal['signal']} @ {signal['entry']}")
    print(f"Target: {signal['target']}  Stop: {signal['stop_loss']}")
Try it now
